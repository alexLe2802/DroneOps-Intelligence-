# Vietnam airspace data

`airspace-zones.geojson` is generated by `npm run airspace:sync`.

- Baseline: Vietnam AIP ENR 5.1, AIRAC 03/26, effective 2026-10-01.
- Supplement: public vector tiles exposed by `cambay.mod.gov.vn`.
- `matched_spatially`: the AIP area intersects the corresponding MOD CB/HCB layer.
- `aip_only`: published in AIP but no corresponding MOD intersection was found. It is retained for review.
- `mod_only_supplement`: geometry visible in the MOD public layer outside the AIP polygons. It is added as a dashed supplementary layer.

The sync script never deletes an AIP area automatically. `airspace-zones-meta.json` records counts and AIP definitions that need manual review. This dataset is a planning aid; live operations must also check the current AIP amendments and NOTAM.
